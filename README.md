# face-recognition-pipeline

End-to-end, benchmarked face recognition pipeline: detect, align, embed, index, verify (1:1) and identify (1:N), exposed through a small API and CLI. The focus is rigorous measurement and privacy-aware engineering.

> **Status: early development (M0).** Nothing is implemented yet.

> **Licensing notice (to be verified in M0).** The code in this repo is MIT-licensed. The pretrained face models this project is planned to use (InsightFace model packs) are typically released for **non-commercial research use only**; the exact license text has **not yet been verified** and will be recorded in `MODEL_CARD.md` and `DATA.md`. Until then, do not assume this project is commercially deployable.

> **Not a surveillance tool.** Faces and embeddings are sensitive biometric data. This project is for research and education only.
