# Security policy

This is a research/portfolio project, not a supported product.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (the repository's **Security** tab, if enabled)
rather than opening a public issue. If it is not enabled, open an issue that says only that you
have a security report, without details, and the maintainer will arrange a private channel.

## Sensitive data

Faces and embeddings are biometric data. Never attach real face images, embeddings, or ID documents
to issues or pull requests.
